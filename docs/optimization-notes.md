# 第一轮优化记录

本轮围绕「计时可信、赛道可保存、导航可用、界面可操作」修改原生 Android 项目。
本文保留首轮修改记录；后续自动过线与赛道历史关联见 [自动计时说明](automatic-timing.md)。

## 修复内容

| 问题 | 修复后行为 |
| --- | --- |
| 手机 GPS 强制要求蓝牙权限与蓝牙开启，Android 12 之前还会请求不存在的权限 | 手机定位独立申请精确位置权限；蓝牙为可选设备能力 |
| 权限结果注册发生在视图创建阶段，重建时可能超过注册时机 | Fragment 初始化时注册权限处理器 |
| Activity 持有自行创建的 LiveFragment，恢复后按钮可能连到旧实例 | Fragment 自持视图；FragmentStateAdapter 负责恢复；计时保存在 Activity 作用域 ViewModel |
| 暂停时只改 UI 计时基准，参考圈和预测仍计入暂停时间 | 圈速、GPS 检查点和预测共享排除暂停的单调时钟 |
| UI 定时刷新用模拟值覆盖真实 Delta / 预测 | UI 只显示参考圈计算结果，无数据时显示占位符 |
| Delta 直接取下一个检查点，圈与圈之间检查点状态不可靠 | 距离插值，逐圈重置检查点，并限制剩余预测时间不为负 |
| 速度为 0 时用漂移推算车速，静止车辆也可能显示移动 | 有效零速保持为零，只在缺少速度时做受精度限制的估计；拒绝无效/过期点 |
| 把卫星状态回调次数当成定位采样率 | 由真实位置样本时间计算更新频率 |
| Room Flow 持续收集导致保存赛道永不继续 | 使用 first() 读取一次数据库快照 |
| 保存失败先停止录制，数据与 UI 状态难以恢复 | 先验证和暂停，成功后结束；失败保留轨迹和起终点，允许重试 |
| 赛道、轨迹点和起终点分多步写入，匹配更新不改名称/长度 | Room 事务统一写入；匹配更新同步名称和长度；累计距离按单次遍历计算 |
| 录制恢复把暂停期间移动也算作赛道距离 | 暂停时清除上一点，恢复后从新点继续累计 |
| 回顾页没有连接实时圈速，重启也不保存 | 连接共享状态，保留最近 500 条完成圈速，按场次最佳值计算差值 |
| 已有赛道列表未接入主导航，录制路由指向不存在的类 | 赛道页接入独立 NavHost，修正类名和返回行为 |
| 地图较晚初始化时丢失轨迹或提前创建标记 | 地图就绪后重绘当前状态，销毁视图时清理地图引用与监听 |
| 个人 JDK 绝对路径写入版本控制，地图缺少网络权限 | 移除个人路径；补充网络权限；API Key 从 Gradle 属性或环境变量注入 |

## UI 调整

- 统一石墨黑、浅色数字与青柠色主操作，替换底部导航图标。
- 将 Activity 上叠放的 HUD 移入实时页，消除与其他页面遮挡及底部导航覆盖。
- 仪表盘区可滚动，开始、过线、结束三个操作固定在底部。
- 自适应主计时字号，赛道录制按钮按宽度分配，避免固定宽度挤出小屏。
- 补齐回顾页统计、空状态、日期和最佳圈标识；结束与清空需要确认。
- 空闲时降低刷新频率，并只更新改变的文本、颜色和窗口状态。
- 移除未使用的 Compose 编译配置与重复 Material 依赖，使用现有 XML / ViewBinding。

## 验证

- JDK 17 + Android SDK 34：`testDebugUnitTest assembleDebug assembleDebugAndroidTest lintDebug`。
- 单元测试共 15 项（含原有 1 项）；新增 14 项覆盖时钟、参考圈、录制距离与数据库保存回归。
- API 36.1 模拟器：AndroidJUnitRunner 共 3 项（含原有 1 项），验证 Room 保存/删除、Activity 重建、圈速回顾与赛道录制导航。
- 本机 Gradle 设备连接器遇到 JDWP 端口冲突，仪器测试通过 ADB 直接执行同一测试 APK。
- Lint 无错误；依赖版本、旧代码文字资源和其他警告仍需后续清理。
- 已检查 411dp 常规屏和 360dp 窄屏实际布局；窄屏下三项计时操作保持可见，仪表盘可滚动。
- [实时页面](screenshots/live.png) / [回顾页面](screenshots/review.png) 为实际模拟器截图，回顾成绩来自集成测试。
