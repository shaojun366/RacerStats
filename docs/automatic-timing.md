# 自动计时与赛道历史

## 已接通的流程

- 实时页可选择已保存赛道；赛道详情的入口会带入赛道 ID。
- 点击启用后等待首次通过起点，经过有限长度的线段才算过线，延长线和反向穿越不记成绩。
- 闭合赛道连续记圈；独立起终点每次从起点计到终点，再等待下一次起点。
- 当前场次锁定赛道，暂停/后台或定位失效会放弃未完成圈，继续后重新等起点。已经完成的成绩保留。
- 新场次重新读取赛道，能反映重命名、改线和删除；进行中的场次使用启动时的配置快照。

## 判定规则

使用单调 GPS 时间戳和局部平面上的线段相交，按位移插值过线时刻。检测带有 1.5～5 米死区、2 秒防重复间隔，并参考首次通过方向。

位置精度必须已知且不大于 20 米，过线前后平均速度至少 2 m/s；超过 3 秒的数据断点或大于 120 m/s 的位置跳变会放弃当前圈。启用前的缓存定位不会启动计时。

最短用时为 `max(3 秒, 赛道长度 / 120 m/s)`，最短累计路程为赛道长度的一半。闭合赛道还需实际离开起点区域至少 20～40 米；静止漂移不累计路程。这些限制用于过滤误触发，不是完整的路线合法性或防作弊检查。

死区确认可能晚于实际过线，因此参考圈会按插值终点截断检查点，过线后的样本计入下一圈。手机定位精度和采样率仍决定实际误差，尚需真机测试。

## 数据兼容

最近 500 条记录继续保存在本地，新增赛道 ID、名称快照与自动/手动标记。旧版记录自动视为未关联赛道的手动记录，单条损坏记录不会导致其他历史丢失。

回顾页支持全部、手动与指定赛道筛选；混合赛道时不显示误导性的全局最佳。清空作用于当前筛选，赛道详情显示该赛道自动成绩的最佳值。删除赛道不会删除已经保存的成绩快照。

## 验证

单元测试涵盖有限线段、日期变更线、死区、方向、连续圈、独立终点、断点和静止漂移，以及插值终点与历史筛选。设备测试涵盖真实保存赛道到自动记圈的链路、暂停、旧 JSON 兼容、重命名及删除后重新开始。

本地验证：41 项单元测试、5 项 API 36.1 设备测试通过；应用/测试 APK 构建成功，Lint 为 0 错误。设备测试使用合成轨迹，[实时页](screenshots/automatic-live.png)和[回顾页](screenshots/automatic-review.png)截图来自实际运行。

地图服务密钥与 Dragy 真机协议仍需开发者配置/确认；本轮没有实现后台定位服务、趋势图和导出。
